## Synthetiq Redact · Hackathon winner

<a href="https://github.com/Synthetiq-HQ/synthetiq-redact" target="_blank" rel="noopener noreferrer">Synthetiq Redact</a> is an open-source, local-first document-redaction system for councils, FOI/SAR teams, and privacy-sensitive casework. It combines OCR, PII detection, human review, local audit trails, and irreversible pixel-burned redactions in a desktop-first workflow.

It won a Hillingdon Council hackathon. The project is designed to support trained reviewers; it does not make final legal disclosure decisions by itself.
